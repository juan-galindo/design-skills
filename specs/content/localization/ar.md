# Locale: SP-AR — Argentine Spanish

Sources: glossary.md, feel-framework.md, cta-guidelines.md, help-center.md

---

## Register

- **Pronoun**: "vos" (informal) — NEVER mix with "tú" forms in the same flow
- **Tone**: Same warmth as es_MX; slightly more direct. Rioplatense conversational style.
- **Key rule**: Always use vos conjugations consistently throughout. Mixing "tú" and "vos" forms in the same flow is a Recommended issue.

---

## Vos Conjugations

| Form | es_MX (tú) | es_AR (vos) |
|---|---|---|
| Present indicative | puedes | **podés** |
| Present indicative | tienes | **tenés** |
| Present indicative | quieres | **querés** |
| Present indicative | sabes | **sabés** |
| Present indicative | haces | **hacés** |
| Imperative | ve | **andá** |
| Imperative | toca | **tocá** |
| Imperative | selecciona | **seleccioná** |
| Imperative | revisa | **revisá** |
| Imperative | haz clic | **hacé clic** |

### Examples
- SP-MX "Ve a tu Perfil" → SP-AR "**Andá** a tu Perfil"
- SP-MX "Puedes aumentar tus límites" → SP-AR "**Podés** aumentar tus límites"
- SP-MX "Haz clic en Actividad" → SP-AR "**Hacé** clic en Actividad"
- SP-MX "¿Quieres convertir?" → SP-AR "¿**Querés** convertir?"
- SP-MX "Puedes ver tu saldo" → SP-AR "**Podés** ver tu saldo"

---

## CTA Grammar

- Use **infinitive** for buttons — same rule as es_MX
- Do NOT use vos imperative in buttons: "Comprá" , "Enviá" — use "Comprar", "Enviar" 
- Vos imperative is only used in body instructions, not in CTAs

---

## FEEL Tone Patterns

| Tone | Pattern |
|---|---|
| Functional | Same structure as es_MX. "Ingresá el monto." (body) / "Ingresar" (CTA) |
| Emotional | Same energy: "¡Listo! Compraste…" — vos verb forms where applicable |
| Educational | "¿Sabías que **podés** programar…?" |

---

## Error Messages

- Shared accountability: **"Tuvimos un problema"** (subject "we" — no vos needed here)
- Apology: **"Perdón"** — more direct; fits AR tone (not "Lo sentimos")

## Key Vocabulary Differences from es_MX

| Concept | es_MX | es_AR |
|---|---|---|
| Go back | regresar | **volver** |
| Got it | entendido | **listo** |
| Tax ID | RFC | **CUIT o CUIL** |
| Apt. No. | número interior | **piso o departamento** |
| Bill / Receipt | recibo | **factura** |
| Phone | celular | **teléfono celular** |
| Computer | computadora | **computadora** (same) |
| Email | correo electrónico | **correo / email** |
| Contact (verb) | contactar | **contactarte** (more natural) |

## Number & Currency Formats

| Format | Rule | Example |
|---|---|---|
| Thousands separator | **Period** | 10.000 |
| Decimal separator | **Comma** | 10.000,25 |
| Percentages | No space | 12,5% |
| Currency | ARS after number | 25.000,50 ARS |
| Dates (numeric) | DD/MM/YYYY | 14/03/2025 |

---

## Future Tense

Use the "ir+infinitive" structure. The conjugated future tense can also be used in more formal contexts.

| Structure | Example |
|---|---|
| ir+infinitive (preferred) | Tus fondos van a estar disponibles pronto. |
| Conjugated future (formal) | Tus fondos estarán disponibles pronto. |

---

## Verb Rules

- **Gerund in titles**: Avoid. Use infinitive instead. "Cómo crear tu cuenta" / "Creando tu cuenta"
- **Gerund post-action**: Avoid for sequential actions. "Creaste tu cuenta y se generó una billetera" / "Creaste tu cuenta, generando una billetera"

---

## Grammar Notes

- App = femenino ("la app") — same as es_MX
- Internet = capital "I" — "Internet" — same as es_MX
- Avoid gendered user references — same as es_MX

---

## What Stays the Same as es_MX

- Infinitive for CTAs
- "¡Listo!" success exclamation
- App = femenino ("la app")
- Sentence case capitalization
- Brand terms untranslated (Bitso, SPEI, etc.)
- Fiat → pesos
- Help Center → Centro de Ayuda
