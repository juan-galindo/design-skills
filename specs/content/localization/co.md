# Locale: SP-CO — Colombian Spanish

Sources: glossary.md, feel-framework.md, cta-guidelines.md, help-center.md

---

## Register

- **Pronoun**: "tú" (informal in digital channels) — "usted" is traditional Colombian but NOT used in app copy
- **Tone**: Clear, polite tone typical of Colombian Spanish. Mostly aligned with es_MX.
- **Key rule**: This locale requires minimal changes from es_MX — primarily vocabulary differences.

---

## Verb Conjugations

Same as es_MX (tú forms):

| Form | Rule | Example |
|---|---|---|
| CTAs / buttons | **Infinitive** | "Comprar", "Enviar", "Continuar" |
| Body copy / instructions | Imperative tú form | "Deposita tu dinero", "Revisa tu saldo" |
| Educational content | Rhetorical questions | "¿Sabías que puedes…?" |
| Success states | Exclamation | "¡Listo!" |

### Help Center Examples
- SP-MX "Ve a tu Perfil" → SP-CO "Ve a tu Perfil" (same)
- SP-MX "Puedes aumentar tus límites" → SP-CO "Puedes aumentar tus límites" (same)

---

## FEEL Tone Patterns

| Tone | Pattern |
|---|---|
| Functional | Same as es_MX. "Ingresa el monto." |
| Emotional | "¡Listo!" — same; slightly less exclamation-heavy |
| Educational | Same rhetorical pattern as es_MX: "¿Sabías que…?" |

---

## Error Messages

- Shared accountability: **"Tuvimos un problema"**
- Apology: **"Lo sentimos"** — same as es_MX. "Disculpe" is acceptable as an alternative.

---

## Key Vocabulary Differences from es_MX

| Concept | es_MX | es_CO |
|---|---|---|
| Computer | computadora | **computador** |
| Tax ID | RFC | **NIT** |
| State / Region | estado | **departamento** |
| Apt. No. | número interior | **apartamento / apto** |
| Zip code | código postal | **código postal** (same) |
| Phone | celular | **celular** (same) |
| City | ciudad | **municipio** |

---

## Number & Currency Formats

| Format | Rule | Example |
|---|---|---|
| Thousands separator | **Period** | 10.000 |
| Decimal separator | **Comma** | 10.000,25 |
| Percentages | No space | 12,5% |
| Currency | COP after number | 25.000,50 COP |
| Dates (numeric) | DD/MM/YYYY | 14/03/2025 |

---

## Future Tense

Use the conjugated future tense — same as es_MX.

Do: Tus fondos estarán disponibles pronto.

---

## Verb Rules

- **Gerund in titles**: Avoid. Use infinitive instead. "Cómo crear tu cuenta" / "Creando tu cuenta"
- **Gerund post-action**: Avoid for sequential actions — same rule as es_MX.

---

## What Stays the Same as es_MX

- "tú" pronoun and conjugations
- Infinitive for CTAs
- Sentence case capitalization
- Brand terms untranslated
- Fiat → pesos
- App = femenino ("la app")
- Help Center → Centro de Ayuda
- Support → equipo de asistencia
- Error apology: "Lo sentimos"
