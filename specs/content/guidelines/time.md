# Time

Source: ZeroHeight — https://bitsodesign.zeroheight.com/styleguide/s/136102/p/33acc0-time

How we write time consistently across all languages and platforms.

---

Use lowercase "am" and "pm" without periods or caps, leaving a space after the number.

| Region | Do | Don't |
|---|---|---|
| All | Do: 8:00 am | Don't: 8:00 p.m. |
| | | Don't: 8:00 P.M. |
| | | Don't: 8:00pm |

**Rationale**
- **Shorter and cleaner:** Takes less space on screens and interfaces.
- **Easier to scan:** Lowercase is less visually intrusive than capitals.
- **Better hierarchy:** The actual time stands out more than the am/pm indicator.
- **Universal standard:** am/pm are Latin abbreviations recognized globally.

---

Use lowercase "h" for hours, "min" for minutes, and "s" for seconds. They require no periods and a space after the number because they're symbols. The "h" is also used as a standard symbol to talk about a specific time or a number of hours.

| Region | Do | Don't |
|---|---|---|
| All | Do: Las que más subieron en las últimas 24 h | Don't: Las que más subieron en las últimas 24 hs. |
| | | Don't: Las que más subieron en las últimas 24 hrs. |
| | Do: Tu retiro se procesó en 2 min | Don't: Tu retiro se procesó en 2 m. |
| | | Don't: Tu retiro se procesó en 2 min. |
| | Do: Procesando... 45 s | Don't: Procesando... 45 sec |
| | | Don't: Procesando... 45 secs. |

> **Note:** "s" may feel less intuitive than "seg" (SP) or "sec" (EN/PT-BR), but we follow the SI universal standard to save space and stay consistent across all languages.
