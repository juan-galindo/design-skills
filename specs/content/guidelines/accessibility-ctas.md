A call to action is the bridge between information and the next step. Good CTAs are clear, specific, and transparent about what happens when users tap them.

---

## Ableist verbs

Some verbs unintentionally reference disability in a negative way. "Enable" and "disable," for example, are commonly used in accessibility contexts to describe people with disabilities. Using them for interface controls can feel insensitive and create confusion.

Use "Turn on" and "Turn off" instead of "Enable" and "Disable" for interface controls and features.

| Region | Do | Don't |
|---|---|---|
| SP-all | Do: Activar · Do: Activado · Do: Activada · Do: Desactivar · Do: Desactivado · Do: Desactivada | Don't: Habilitar · Don't: Habilitado · Don't: Habilitada · Don't: Deshabilitar · Don't: Deshabilitado · Don't: Deshabilitada |
| PT-BR | Do: Ativar · Do: Ativado · Do: Ativada · Do: Desativar · Do: Desativado · Do: Desativada | Don't: Habilitar · Don't: Habilitado · Don't: Habilitada · Don't: Desabilitar · Don't: Desabilitado · Don't: Desabilitada |
| EN | Do: Turn on · Do: Turned on · Do: Activate · Do: Deactivate | Don't: Enable · Don't: Enabled |

**Rationale**

- **Cognitive load:** In English, "enable/disable" are more abstract terms that can confuse users. "Turn on/off" are more transparent options that clearly communicate the action being performed.
- **Accessibility considerations:** "Disabled" and its translations in Spanish and Portuguese are commonly used in accessibility contexts to refer to people with disabilities. Reserving this term for accessibility is a kind consideration.

## Sensory verbs

Some verbs take for granted that all users share the same physical abilities. "See" or "watch," for example, assume the user can see the screen. This can exclude users who rely on screen readers or other assistive technologies.

Avoid verbs that assume the user can see the screen. Use neutral alternatives instead.

|---|---|---|---|---|---|
| Revisar | | | | Review | Avoid "see" or "ver" |
