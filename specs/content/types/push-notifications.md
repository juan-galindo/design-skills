# Push Notifications — Content Guidelines

Source: transactionalEmailPushNotifications.pdf (Bitso, March 2026)

---

## Purpose

A push notification informs the user of an event or update — it may or may not be user-initiated.

**Characteristics**:
- Designed for **timeliness** — appear within the app (in addition to or instead of email)
- Broader use cases: price alerts, security alerts, new feature announcements, reminders

---

## Key Review Criteria

- **Ultra-brief**: subject + 1–2 lines max
- **Timely**: message is relevant at the moment it's received
- **Clear action or outcome**: user understands what happened and what (if anything) to do
- Apply the same FEEL framework at a compressed scale (see `core/feel-framework.md`)
- Apply all glossary and tone-of-voice rules — no forbidden terms, correct locale terms

---

## Structure: Value First, Context After

- "Se ha registrado una nueva operación en tu cuenta."
- "Recibiste $1,200 de Juan Pérez."

---

## Rules

- Personalize when possible: user name, amount, asset type.
- Be specific about what requires action vs. what is informational.
- In crypto: include a reference price when relevant — "Tu BTC bajó 5% hoy. Precio actual: $42,300 USD."
- **Never** use notifications to incite buying/selling based on market movements — regulatory risk.
- For security alerts: serious tone, clear immediate action.
- Do not add artificial urgency or FOMO: "¡Solo quedan 2 horas para esta oportunidad!"

---

## Examples by Type

```
Received deposit: "Recibiste $5,000 MXN. Ya están en tu cartera."
Outgoing transfer: "Enviaste $2,000 a Ana García."
Price alert: "Bitcoin bajó 8% en las últimas 24h. Precio actual: $41,200 USD."
Security alert: "Detectamos un inicio de sesión desde un nuevo dispositivo. ¿Fuiste tú?"
Feature update: "Tu portafolio ahora muestra acciones y ETFs en tiempo real."
```

---

## Tone by Context

| Type | Tone | Notes |
|---|---|---|
| Transaction confirmed | Warm, factual | Use user name and specific amount |
| Price movement | Informational, neutral | Include current price; no "buy now" framing |
| Security alert | Serious, direct | Immediate action clear; no softening |
| Feature/product update | Confident + Fresh (brief) | One sentence; no jargon |
| Reminder | Friendly, functional | Specific to what action is needed |

---

## FEEL Checklist for Push Notifications

- [ ] Message is understandable without any prior context
- [ ] Specific amount, asset, or action named (not generic)
- [ ] Tone matches the event type (no "fresh" for security alerts)
- [ ] No forbidden terms or regulatory red flags
- [ ] No artificial urgency or FOMO language
- [ ] 1–2 lines maximum
