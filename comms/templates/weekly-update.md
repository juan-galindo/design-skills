# Weekly Update — Template

**Format:** Written — Slack message or email
**Audience:** Design team
**Cadence:** Weekly (end of week or start of next)
**Owner:** Design lead or individual designer

> See [writing principles](../index.md#writing-principles) before filling in.

---

## Structure

### TL;DR ← write this last, lead with it

One sentence. The single most important thing that happened or needs attention this week.
Use an action title: assert the outcome, not the activity.

> "We unblocked Stream 1 by aligning on token naming — Sprint 3 can start on time."
> Not: "This week we worked on tokens."

---

### Progress

What moved forward. Use bullet points, one line each.
Each line = one outcome, not one task.

- [What was completed or advanced, and why it matters]
- [What was completed or advanced, and why it matters]

---

### Blockers

What is stopped and needs action from someone else.
Name the blocker, name the owner, name the ask.

- **[Blocker]** — Waiting on [person / team] to [specific action]. Needed by [date].

No blockers → write "None."

---

### Next week

What the team will focus on. Two or three items max.
Write intent, not a task list.

- [What we plan to move forward and the expected outcome]
- [What we plan to move forward and the expected outcome]

---

### Links

Figma, Jira, Confluence, PRs — only what's directly relevant.

- [Label](url)

---

## Slack format (condensed)

For async Slack posts, collapse into this format:

```
*Weekly Update — [Team / Project] · [Date]*

*TL;DR:* [One-sentence takeaway]

*Progress*
• [Outcome]
• [Outcome]

*Blockers*
• [Blocker] — needs [person] to [action] by [date]

*Next week*
• [Intent]

[Links if needed]
```

---

```
*Weekly Update — Design System · MAY 9, 2026*

*TL;DR:* Token cleanup is unblocked — Stream 1 moves to Defining phase next week.

*Progress*
• Audited and renamed 140 color tokens to match the MDS naming spec
• Aligned with Eng on the token AI pipeline output format

*Blockers*
• Production component handoff — needs PM sign-off on scope before we can start Sprint 3. Needed by MAY 12.

*Next week*
• Define the Tokens AI pipeline end to end
• Start component visualization spec

[Figma – Token Audit](url) · [Jira – Stream 1](url)
```
