# Content — Agent Guide

> AI agents automatically detect this file when working inside `docs/content/`.

This folder stores produced content artifacts — written outputs from the Content Design team. It is distinct from `specs/content/`, which stores writing guidelines and templates used as inputs.

---

## Folder map

| Folder | What it stores | Agent instructions |
|--------|---------------|-------------------|
| `help-center/` | Published and draft help center articles, organized by locale | See `help-center/README.md` for naming convention and folder structure. Templates and writing rules live in `specs/content/types/help-center/`. |
| `project-keys/` | Exported Lokalise content key JSON files per project | Machine-generated by the `design-content-keys-generation` skill. Never edit manually. |

---

## General rules

- Help center articles go in the matching locale subfolder: `help-center/es-mx/`, `help-center/es-ar/`, `help-center/es-co/`, `help-center/pt-br/`, or `help-center/en-us/`.
- File names use kebab-case: `how-to-buy-bitcoin.md`, `how-market-hours-work.md`.
- Always lead with `es-mx` when producing multi-locale articles.
- Before writing or reviewing any article, load `specs/content/types/help-center/templates.md` and `specs/content/types/help-center/writing-guidelines.md`.
- Run the checklist in `specs/content/types/help-center/checklist.md` before marking an article ready.
