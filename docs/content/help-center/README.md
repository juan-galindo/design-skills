# Help Center Articles

This folder stores published and draft help center articles, organized by locale.

## Folder structure

```
help-center/
├── es-mx/   🇲🇽  Spanish — Mexico (lead locale, always first)
├── es-ar/   🇦🇷  Spanish — Argentina
├── es-co/   🇨🇴  Spanish — Colombia
├── pt-br/   🇧🇷  Portuguese — Brazil
└── en-us/   🇺🇸  English — United States
```

## Naming convention

Use kebab-case and keep it descriptive:

```
how-to-buy-bitcoin.md
how-to-increase-account-limits.md
what-is-a-stablecoin.md
```

## Writing guidelines

- Templates → [`specs/content/types/help-center/templates.md`](../../../specs/content/types/help-center/templates.md)
- Writing guidelines → [`specs/content/types/help-center/writing-guidelines.md`](../../../specs/content/types/help-center/writing-guidelines.md)
- Self-review checklist → [`specs/content/types/help-center/checklist.md`](../../../specs/content/types/help-center/checklist.md)
- New listings template → [`specs/content/types/help-center/templates-new-listings.md`](../../../specs/content/types/help-center/templates-new-listings.md)

Always lead with SP-MX and create a file per locale when translating.
